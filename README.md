# Project 5 — Full-Stack Deployment & Project Architecture

NovaStore is a full-stack e-commerce product catalog.

Features:
- Node.js + Express backend
- REST API at `/api/products`
- client-side routing
- search and category filtering
- cart with localStorage persistence
- responsive frontend
- compact production CSS and JS
- ready for Render deployment

Run locally:
1. Open the folder in VS Code
2. Terminal > New Terminal
3. `npm install`
4. `npm start`
5. Open `http://localhost:3000`

Deploy:
Push to GitHub, then create a Render Web Service.
Build command: `npm install`
Start command: `npm start`
